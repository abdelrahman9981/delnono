# delnono

DElnono Flutter application

## Spec-Driven Development

This project uses [GitHub Spec Kit](https://github.com/github/spec-kit) with
Claude Code. Start Claude Code from the project directory and use the installed
skills to develop features:

1. `/speckit-constitution` - establish or update project principles.
2. `/speckit-specify <feature>` - describe the feature and its requirements.
3. `/speckit-clarify` - resolve ambiguities when needed.
4. `/speckit-plan` - create an implementation plan.
5. `/speckit-tasks` - generate actionable tasks.
6. `/speckit-analyze` - check artifacts for consistency when needed.
7. `/speckit-implement` - execute the tasks.
8. `/speckit-converge` - check for remaining work.

Project templates and scripts are in `.specify/`; the Claude Code skills are in
`.claude/skills/`.
