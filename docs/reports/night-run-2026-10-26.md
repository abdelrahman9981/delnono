## Run it yourself

```sh
# Emulators with the seed data (auth, Firestore, Functions)
(cd functions && npm run build) && functions/node_modules/.bin/firebase emulators:start --only auth,firestore,functions --import=./emulator-seed

# Guardian app on the iOS simulator
flutter run -d "iPhone 17" --dart-define=USE_EMULATOR=true

# Clinic dashboard in Chrome (staff: doctor@demo.delnono / sec1@demo.delnono, password Delnono-2026)
flutter run -d chrome -t lib/dashboard/main.dart --dart-define=USE_EMULATOR=true
```

Emulator sign-in uses test numbers; the code is shown by the Auth emulator (no SMS). The seeded family is +20 100 000 0001.
