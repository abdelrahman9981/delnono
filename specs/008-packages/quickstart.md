# Quickstart: Packages

1. Guardian app, signed out: Home → «الباقة السنوية» → both clinics' prices and the rules.
2. Sign in as a seeded family with a package: «حسابي» → «الباقة» shows each child, the end date, «سارية».
3. Dashboard (`sec1@demo.delnono`): open a child whose package ends within 14 days → "تجديد الباقة" → the file shows the renewal from the day after the end.
4. App: the notifications page lists "باقتك هتخلص بعد ١٤ يوم" once due; with a renewal, no reminder.

Automated: `flutter test`, `cd functions && npm test`, simulator integration, `scripts/dashboard_e2e.sh` at merge.
